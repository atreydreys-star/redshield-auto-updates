# RedShield Auto — обновления

Публичный канал APK личного неофициального Android-помощника «Сеть → Red Shield».

Здесь публикуются только подписанные APK, контрольные суммы и описание изменений. Это не приложение разработчика Red Shield VPN. Для работы требуется установленный Red Shield VPN.

Адрес канала для помощника: `https://raw.githubusercontent.com/atreydreys-star/redshield-auto-updates/main/latest.json`.

Приложение проверяет размер, SHA-256, пакет и совпадение подписи APK. Установка подтверждается в системном окне Android. Пароли, настройки и журналы телефона в этот репозиторий не передаются.
